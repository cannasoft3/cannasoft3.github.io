## Troubleshooting & FAQ



### Issue: Blur API connection fails

**Solution:**  
1. Check internet connection.  
2. Verify Blur API status.  
3. Check Windows Firewall: allow BlurNFTSniper.zip through inbound/outbound rules.

### Issue: Transactions not landing

**Solution:**  
1. Increase gas price or max fee.  
2. Ensure sufficient ETH balance for transaction fees.  
3. Check if the NFT is still available.  
4. Try a different RPC endpoint.

### Issue: Auto-sniping not triggering

**Solution:**  
1. Ensure auto-sniping is enabled.  
2. Check that the price threshold is correctly set.  
3. Verify that the collection filters are not too restrictive.  
4. Restart the tool.
