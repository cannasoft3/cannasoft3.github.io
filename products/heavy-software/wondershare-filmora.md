### Issue: Filmora not detecting GPU

2. Ensure the GPU is supported (NVIDIA GTX 1060+, AMD RX 580+).  
3. Check that GPU acceleration is enabled: Edit → Preferences → Performance → Enable GPU Acceleration.  
4. Restart Filmora.

### Issue: Export fails or crashes

**Solution:**  
1. Reduce the output resolution or frame rate.  
2. Close other GPU-intensive applications.  
3. Update GPU drivers.  
4. Try exporting to a different format.

### Issue: Stock media not downloading

**Solution:**  
1. Check internet connection.  
2. Disable VPN if not required.  
3. Check Windows Firewall: allow Filmora.zip through inbound/outbound rules.  
4. Restart Filmora.
