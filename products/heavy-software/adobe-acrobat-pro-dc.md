## Troubleshooting & FAQ



### Issue: Adobe Acrobat not opening PDFs

**Solution:**  
1. Set Acrobat as the default PDF viewer: Settings → Default Apps → PDF → Adobe Acrobat.  
2. Repair the installation: Help → Repair Installation.  
3. Update Acrobat: Help → Check for Updates.

### Issue: OCR not working

**Solution:**  
1. Ensure the OCR language pack is installed: Edit → Preferences → OCR → Install Language Pack.  
2. Check that the scanned document is clear and high-resolution.  
3. Run OCR manually: Tools → Scan & OCR → Recognize Text.

### Issue: E-signature not working

**Solution:**  
1. Ensure Adobe Sign is configured: Tools → Adobe Sign → Sign in.  
2. Check internet connection.  
3. Verify that the recipient's email address is correct.
