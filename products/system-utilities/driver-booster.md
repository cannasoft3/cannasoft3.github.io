## Overview

Driver Booster is an automatic driver updater for Windows 10/11 x64, developed by IObit. The application scans your system for outdated, missing, or faulty drivers and updates them automatically from a database of over 8 million drivers for hardware components, peripherals, and devices.

Driver Booster supports drivers for NVIDIA, AMD, Intel, Realtek, Broadcom, and thousands of other hardware manufacturers. The application includes a driver backup and restore feature, automatic driver installation, and offline driver installation for systems without internet access.

## Troubleshooting & FAQ



### Issue: Driver Booster not detecting outdated drivers

**Solution:**  
1. Update the application: Settings → Updates → Check for Updates.  
2. Restart Driver Booster.  
3. Run a new scan: Scan → Scan.

### Issue: Driver update fails

**Solution:**  
1. Check internet connection.  
2. Try updating drivers one at a time.  
3. Use the offline driver installation feature.  
4. Download drivers manually from the manufacturer's website.

### Issue: System instability after driver update

**Solution:**  
1. Restore the previous driver: Backup → Restore → Select backup → Restore.  
2. Create a restore point before future updates.  
3. Add the problematic driver to the ignore list.
