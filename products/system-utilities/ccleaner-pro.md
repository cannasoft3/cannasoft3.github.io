## Troubleshooting & FAQ



### Issue: CCleaner not detecting junk files

**Solution:**  
1. Update cleaning rules: Options → Updates → Check for Updates.  
2. Restart CCleaner.  
3. Run a new scan: Custom Clean → Analyze.

### Issue: Registry cleaner causing issues

**Solution:**  
1. Always back up the registry before fixing issues (CCleaner prompts for backup).  
2. If issues occur, restore the backup: File → Restore Registry Backup.  
3. Run fewer registry scans per session.

### Issue: Real-time monitoring not working

**Solution:**  
1. Ensure monitoring is enabled: Options → Monitoring → Enable.  
2. Check that the threshold is set correctly.  
3. Restart CCleaner.
