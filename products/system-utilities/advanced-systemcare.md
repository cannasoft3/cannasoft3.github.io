## Troubleshooting & FAQ



### Issue: Advanced SystemCare not detecting junk files

**Solution:**  
1. Update the application: Settings → Updates → Check for Updates.  
2. Restart Advanced SystemCare.  
3. Run a deep scan: Home → Deep Scan → Scan.

### Issue: Real-time protection not working

**Solution:**  
1. Ensure real-time protection is enabled: Protect → Enable.  
2. Check that the protection modules are correctly configured.  
3. Restart Advanced SystemCare.

### Issue: Internet booster not improving speed

**Solution:**  
1. Ensure internet booster is enabled: Speed Up → Internet Booster → Optimize.  
2. Check that your internet connection is stable.  
3. Try a different DNS server (e.g., Google DNS: 8.8.8.8).
